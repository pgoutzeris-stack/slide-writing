ROOTS PowerPoint Automation

Slide Writing

Eine eigene, zero-dependency PPTX-Engine, die bestehende PowerPoint-Master ausliest und neue Consulting-Folien im selben Design erzeugt.

GitHub Repository Zielbild lesen 
$ slide-writing validate deck.json
OK

$ slide-writing generate \
  --template master.pptx \
  --spec deck.json \
  --out consulting-deck.pptx

consulting-deck.pptx
Parser

Master verstehen

Themes, Slide Master, Layouts, Platzhalter, Folieninventar und Relationships werden direkt aus OOXML gelesen.

Builder

Folien erzeugen

Neue Slides referenzieren Original-Layouts und erzeugen native, editierbare PowerPoint-Shapes, Tabellen, Text und Bilder.

Consulting

Bausteine nutzen

Agenda, KPI-Kacheln, Harvey Balls, Wasserfall, Balken, Timelines, Vergleichsmatrizen und Callouts sind eingebaut.

Automatisierung ohne externe Runtime

Slide Writing läuft mit der Python-Standardbibliothek und ist damit reproduzierbar, prüfbar und exakt auf den ROOTS-Folienbau zugeschnitten.
